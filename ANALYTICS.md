# Analytics

## Primary KPIs

Initial targets:

- 10k–20k monthly plays
- 100–300 DAU
- 12–18 minute average session
- D1 retention: 25%+
- D7 retention: 10%+
- D30 retention: 5%+
- 2–5% purchaser conversion

These are working targets, not guarantees.

## Event instrumentation

Track at minimum:

- tutorial_started
- tutorial_completed
- starter_pet_selected
- pet_fed
- pet_played_with
- quest_started
- quest_completed
- minigame_started
- minigame_completed
- shop_opened
- item_purchased
- house_customized
- session_10_minute
- session_15_minute
- return_session

## Diagnostic framework

**Lots of impressions, few joins**
→ marketing/game-page problem.

**Lots of joins, early exits**
→ onboarding or first-minute problem.

**Long sessions, weak returns**
→ progression/retention problem.

**Good returns, weak purchases**
→ monetisation/value problem.

**Good retention and purchases, weak growth**
→ acquisition/marketing problem.

## Weekly review

Review:

- DAU/CCU
- New vs returning players
- Session length
- D1/D7/D30 retention
- Funnel drop-offs
- Pet popularity
- Quest completion
- Minigame engagement
- Purchases
- Product performance

Classify work:

- GREEN = keep
- YELLOW = improve
- RED = remove/rework
- ROCKET = expand aggressively
