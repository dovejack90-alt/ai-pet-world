# AI PET WORLD 🐾

AI PET WORLD is a Roblox pet-collection and friendship game built around a simple loop:

**Adopt → Care → Explore → Complete quests → Earn → Collect → Return**

The game is designed for short, satisfying sessions that naturally become repeat visits.

## MVP goal

Prove that the first 10–15 minutes are fun before expanding the world.

### MVP player journey

1. Spawn in Pet Town.
2. Choose a starter pet.
3. Meet the pet and see its personality.
4. Complete a first care action.
5. Complete a simple quest.
6. Earn coins and XP.
7. Spend coins on a small reward.
8. Save progress.
9. Return later with progress intact.

## Product principles

- Mobile-first.
- Fast onboarding.
- Friendly, child-appropriate content.
- No unrestricted AI chat with children.
- AI is primarily used behind the scenes for controlled content variation, design, development, testing and marketing.
- Purchases should be optional, clear and low-cost.
- Exact-value purchases are preferred over paid randomised rewards.
- Build modular systems so features can be added without rewriting the game.
